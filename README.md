# Usage of Concept Drift Measures for Meta Learning
  &nbsp; This repository contains an experiment that evaluates the contribution of concept drift measures as meta features for predicting some base models performances. It's worth noticing that the this repository should have been a fork to [Fernanda A. Melo's repository](https://github.com/feamelo/drift-meta-learning/tree/drift_alert_exp), as much of her code was kept or adapted.

## Installation and Use
 First, clone this repository and move to it

  ```
    git clone https://github.com/henriqueramosqs/meta-learning-concept-drift
    cd meta-learning-concept-drift
   ```

 then, install the project's requirements

 ```
 pip install requirements.txt
```
   
  To generate the metabases, type
  ```
   python3 -m notebooks.experiment
```
this will execute the main experiment pipeline using the parameters specified at `DATASETS_METADATA` in `notebooks/experiment.py`

Once the metabases are ready, generate the results dataframes with 

  ```
   python3 -m notebooks.drift_contribution_generator
```

Main results evaluation canbe then seen at `results/result_importances/` and `results/result_gain/`
  <br>
To include a new dataset, one must add it to the data directory, in arff format and with target variable named "class"
